- [Centralne etapy R0–R8](https://github.com/serafin1367/alice-infra/issues)

### Jak prowadzić pracę

1. Utwórz szczegółowe Issues w repozytorium, którego kod dotyczy zmiana, z identyfikatorem `[ALICE-RM Rn][Pn]` w tytule i linkiem do centralnego etapu.
2. Zaznaczaj kryteria akceptacji w Issue, łącz Pull Request przez `Closes #numer` **w tym samym repozytorium**, a dla pracy między repozytoriami linkuj pełny URL.
3. Zamknij etap centralny dopiero po sprawdzeniu spełnienia kryteriów jego zadań, nie tylko po dopisaniu dokumentacji.
4. Dodaj nowe Issues do tego indeksu, jeżeli mają być widoczne jako oficjalny element programu prac. Dynamiczne wyszukiwanie pokazuje też nowe zadania z prefiksem `ALICE-RM`.
5. Nie stosuj przypisywania niezweryfikowanych wykonawców ani sztucznych dat zakończenia.
